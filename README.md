# Blazor Rich Text Editor — Markdown Editor

A minimal Blazor sample demonstrating the Markdown editing capabilities of the Syncfusion Rich Text Editor component. The project shows how to enable Markdown mode, configure formatting options, and extend formatting with custom rules.

## Overview

This sample illustrates using the RTE as a Markdown editor in a Blazor application. It includes examples for default Markdown behavior and a custom formatting scenario to demonstrate how the editor converts between Markdown and rich text.

Documentation:[ https://blazor.syncfusion.com/documentation/rich-text-editor/markdown](https://blazor.syncfusion.com/documentation/markdown-editor/getting-started-webapp)

Online examples:

- [https://blazor.syncfusion.com/demos/rich-text-editor/markdown-overview?theme=fluent](https://blazor.syncfusion.com/demos/markdown-editor/overview?theme=fluent2)
- [https://blazor.syncfusion.com/demos/rich-text-editor/markdown-custom-format?theme=fluent](https://blazor.syncfusion.com/demos/markdown-editor/custom-format?theme=fluent2)

## Features

- Enable Markdown mode in the Rich Text Editor
- Convert between Markdown and HTML
- Custom Markdown formatting example

## Prerequisites

- Visual Studio 2022 (or later)
- The .NET SDK required by the solution

## Run the project

1. Clone the repository to a local folder.
2. Open the solution in Visual Studio 2022.
3. Restore NuGet packages by rebuilding the solution or run `dotnet restore`.
4. Build and run the project from Visual Studio.

Optional CLI commands:

```powershell
dotnet restore
dotnet build
```

## Troubleshooting & support

If you encounter issues, confirm that packages are restored, the project builds, and the license key is registered correctly. For more details about Syncfusion components consult the Syncfusion Blazor documentation.
